# コロニー資産ターミナル (Colony Asset Terminal)

宇宙コロニーに住む主人公が、スラムで拾った古い端末「CAT-OS」を使って仮想通貨「クレジット（CR）」を様々な方法で運用し、最終的にコロニー全体の買収・独立を目指すシミュレーションゲーム。

---

## 主な特徴とシステム

### 1. 景気レジームシステム（戦略の核）
市場は「好況 / 安定期 / 減速期 / 恐慌」の4つのレジームを5〜12日周期で移行します。
- 各レジームは株価・投信のドリフト、ボラティリティ、施設収入倍率（x1.15〜x0.70）、銀行金利に影響。
- レジーム移行の前には専門家の予測ニュースが配信され、カジノの「情報屋」から次のレジームを確実に購入できる。
- 恐慌中は銀行金利ゼロ・株価急落。債券ファンドだけがプラスになる「安全資産」として機能する。
- 恐慌を乗り切ると実績「恐慌を生き延びる」を獲得。

### 2. 多彩な資産運用手段
- **中央銀行預金**: 50万CRまで日歩1%、超過分は0.05%の段階金利。恐慌中は金利ゼロ。
- **投資信託**: リスク・リターンに応じた全5コース（債券型・インデックス型・資源商品型・グロース型・量子AI超レバレッジ型）。
- **株式市場**: 5つのセクター銘柄（採掘重工、バイオ製薬、AIインプラント、軌道運輸、リゾート）。約12%で「重大材料」ニュースが事前配信され、翌日の急騰・急落（±6〜18%）が予告される。先を読んで売買する情報戦。
- **星間為替 (FX)**: レバレッジ（1倍〜20倍）取引、ロング／ショート対応。証拠金維持率50%で強制ロスカット、レバレッジに応じた毎日のキャリー費用も発生。
- **コロニー施設投資**: 酸素プラント、宇宙水耕農園、核融合発電所、量子AIラボ、貿易ドック、重力維持リング。日収の3%がメンテ費用としてかかる。

### 3. 判断型イベント
日数を進めると「小惑星接近警報」「労組の賃上げ交渉」「ハッカーの脆弱性」などのイベントが発生。支出して被害を回避するか、節約して施設停止などのペナルティを負うか、資産状況に応じた判断が問われる。

### 4. カジノ＆ギャンブル（時間経過なし）
- **コロニー・ルーレット**: 赤黒・大小・特定ナンバー。出目0の「過電流HAZARD」による大負けリスクあり。HAZARDに逆張りする高配当ベットも可能。
- **ハイ&ロー**: 出目予測で連続勝利を目指す。途中で治安部隊の手入れリスクあり。
- **ネオ・スロット**: 3リールスロット。ドクロ（SKULL）揃いによる端末暴走ペナルティあり。
- **情報屋**: 2,500 CRで「次のレジーム」を確実に開示。銘柄の重大材料も漏らしてくれることがある。
- カジノの期待値は約92%で長期では必ず負ける。1回のベットは所持金の20%までに制限。カジノは資金調達ではなく、情報の入手先として位置づけられている。

### 5. 生活コストと資産圧力
純資産10万CRを超えた分には0.2%/日のコロニー生活コストがかかる。銀行預金に寝かせるだけでなく、資産を成長させる運用が常に求められる。

### 6. セーフティネット＆クリア条件
- **ベーシックインカム（生活保障手当）**: 所持金が10,000 CR未満になった場合、日付を進めると毎日5,000 CRが自動支給され、破産を防止。
- **コロニー買収**: 純資産・手持ち資金100,000,000 CR（1億クレジット）を達成することで、コロニー統轄権の買収を執行してゲームクリア。

### 7. レトロ＆サイバーな演出
- **ドット絵アニメーション**: 宇宙服姿のキャラクターが画面上で足踏み・呼吸し、資産状況に応じたステータスを表示。
- **内蔵プロシージャルBGM**: Android AudioTrackを活用したリアルタイム波形合成により、「8-bit Chiptune」「Sci-Fi Synth」「なし（OFF）」を外部音源ファイルなしで再生。
- **CRTディスプレイ・テーマ**: CRT Green、CRT Amber、Flat Grey、Cyber Cyanの4テーマ切り替え。

## 開発環境・ビルド
- **言語**: Kotlin (100%)
- **UIツールキット**: Jetpack Compose (Material3)
- **アーキテクチャ**: MVI / MVVM (ViewModel + StateFlow + Repository)
- **ビルドツール**: Gradle (Kotlin DSL)
- **対象環境**: Android 8.0 (API 26) 以上

```bash
# 単体テスト実行
./gradlew testDebugUnitTest

# APKビルド
./gradlew assembleDebug
```
成果物APK: `app/build/outputs/apk/debug/app-debug.apk`
